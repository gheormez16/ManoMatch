# ManoMatch

**Manos expertas, a un clic.**

ManoMatch es una plataforma que conecta a personas que necesitan un arreglo en casa (fontanería, electricidad, pintura, etc.) con profesionales ("manitas") disponibles cerca, de forma rápida, segura y con precio claro.

## La idea

1. **Pide** — el usuario describe el problema (fontanería, electricidad, pintura...)
2. **Elige** — selecciona entre los profesionales disponibles
3. **Arregla** — el profesional resuelve el trabajo

Rápido · Seguro · Precio claro

## El rival

Competidor principal: **TaskRabbit**.

### Análisis FODA

- **Fortalezas:** escalabilidad, pagos seguros
- **Oportunidades:** demanda constante, auge del trabajo freelance/por encargo
- **Debilidades:** sin presupuesto inicial, marca nueva
- **Amenazas:** aplicaciones similares, malas reseñas, posibilidad de no cobrar comisiones

## Modelo de negocio

**Ingresos:**
- Anuncios
- Suscripciones
- Cuentas Premium
- Comisiones por servicio

**Costes:**
- Publicación / lanzamiento
- Salarios
- Marketing
- Mantenimiento (servidores, dominio...)

**Punto de equilibrio estimado:** 14–18 meses.
